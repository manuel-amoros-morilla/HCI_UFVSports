Quiero crear esto con Figma: # UFVSports — Mobile Application Design Prompt
### Universidad Francisco de Vitoria (UFV)

## 1. Project Overview

Design and generate a high-fidelity, interactive mobile application called **UFVSports**, intended for students of Universidad Francisco de Vitoria (UFV), Madrid, Spain.

The application allows students to:
- Access the university gym using a QR code.
- Book sports facilities.
- View their personal reservations.
- Explore and book sports activities.
- Check gym occupancy.
- Manage their personal profile.

Create a complete, functional mobile prototype with all screens, navigation flows, and interactive elements.

The design must be professional, modern, intuitive, and clearly connected to the visual identity of Universidad Francisco de Vitoria.

Do not rely on external documents or previously uploaded files. All requirements are explicitly defined below.

# 2. Visual Identity and UI Design

### Brand Identity

The application must visually reflect Universidad Francisco de Vitoria.

Use an institutional, elegant, and modern visual style inspired by the university's identity.

### Color Palette
- Primary UFV Blue: #003B71
- Secondary Blue: #005A9C
- White: #FFFFFF
- Light Gray: #F4F6F8
- Dark Gray: #263238
- Success Green: #2E7D32
- Error Red: #C62828
- Warning Orange: #ED8B00

Use blue as the primary color for buttons, navigation, and highlights.

### Design Style
- Modern and minimalist.
- Clean and premium sports-app aesthetic.
- Rounded cards (12–16 px radius).
- Clear visual hierarchy.
- Consistent iconography.
- Subtle shadows.
- Generous spacing.
- High-quality sports photography.
- Accessible typography.
- Mobile-first design.

Use Inter or a similar modern sans-serif typeface.

Create the application using a 390 × 844 px mobile frame.
